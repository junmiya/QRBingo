QRコードで参加、番号は自動マーク。TV・配信でも遊べるビンゴ

オンラインで遊ぶ

TV・YouTube Live などの配信や、離れた場所からの参加向け。カードはネットワークで配られ、抽選番号は全員の画面に自動マーク。リーチ/ビンゴは全員に速報表示、チャットや開始カウントダウン、投げ銭(応援)にも対応します。

ゲームを主催する(ホスト) ゲームを作成して参加用QRを表示、抽選ボタンを押すだけ。順位も自動で確定します ゲームに参加する(プレイヤー) QRコードかゲームコードで参加。番号は自動マーク、ビンゴも自動で申告されます

あそびかた(オンライン)

  1. ホストが「ゲームを主催する」でゲームを作成 → 参加用QRコードとゲームコード(4文字)が表示。TV・配信画面に映します。作成時にチャットや開始カウントダウンのON/OFFも選べます。
  2. 参加者はスマホでQRを読み取る(またはゲームコード入力)+ニックネーム入力で、自分だけのビンゴカードが配られます。ログイン不要。
  3. カウントダウンを使うと、参加者の画面に「開始まで 3:00」のような残り時間が表示されます。
  4. ホストが「抽選する!」を押すと番号が全員にリアルタイムで届き、カードは自動マーク(タップ不要)。
  5. 誰かがリーチ/ビンゴになると全員の画面に速報が流れます。チャットON時はみんなで会話できます。
  6. 勝利条件(初期は1ライン)に達すると自動でビンゴ申告され、順位が表示されます。
  7. ホストが「ゲームを終了」すると順位が確定。上位(景品数まで)の当選者に当選コードが出るので、主催者に伝えて景品を受け取ります。
  8. ホストが受け取り設定をしていれば、参加者は投げ銭(応援)を送れます(勝敗には無関係)。

順位は「何球目でビンゴしたか」だけで決まるので、通信の速さや申告の早さは無関係。景品数を超える同着は公平に抽選されます。

ログインはホスト画面上部の「アカウント」から(Google または メール/パスワード)。ログインが必要なのはプラン購入・投げ銭の受け取りをする主催者だけで、参加者は不要です。

オフラインで遊ぶ(会場向け・サーバー不要)

同じ会場で、ホストが番号を読み上げて各自で手マークする昔ながらの方式。ネット接続も Firebase もログインも不要。1台の端末でホスト、参加者はスマホでカードを受け取ります。

ホスト QR表示・抽選・ビンゴ検証 プレイヤー カード受取・手動マーク

あそびかた(オフライン)

  1. ホストが「ホスト」画面でゲームを作成 → 参加用QRコードが表示されます。会場のスクリーンや紙で共有します。
  2. 参加者はスマホでQRを読み取ると、自分のビンゴカードが表示されます(オフラインなのでその端末内で完結)。
  3. ホストが「抽選」ボタンで番号を選び、声で読み上げます。
  4. 参加者は呼ばれた番号を自分でタップしてマークします。
  5. 1ライン(初期設定)そろったら「ビンゴ!」。参加者はカードに表示されるQRをホストに見せると、ホスト画面でその場で正しいカードか検証できます。

通信環境が不安定な会場や、サーバー費用をかけたくないときに最適。カード配布はQRの読み取り時のみネットを使い、以降はオフラインで進行できます。
