QRBingo

QRコードで参加、番号は自動マーク。TV・配信でも遊べるビンゴ

📡 オンラインで遊ぶ

TV・YouTube Live などの配信や、離れた場所からの参加向け。カードはネットワークで配られ、抽選番号は全員の画面に自動でマークされます。

🎪 ゲームを主催する(ホスト) ゲームを作成して参加用QRを表示、抽選ボタンを押すだけ。順位も自動で確定します 🎫 ゲームに参加する(プレイヤー) QRコードかゲームコードで参加。番号は自動マーク、ビンゴも自動で申告されます

▶️ あそびかた(オンライン)

1. ホストが「ゲームを主催する」でゲームを作成すると、参加用QRコードとゲームコード(4文字)が表示されます。TV・配信画面に映してください。
2. 参加者はスマホでQRコードを読み取る(またはゲームコードを入力)し、ニックネームを入れると、自分だけのビンゴカードが配られます。
3. ホストが「抽選する!」を押すと、番号が全員の画面にリアルタイムで届き、カードは自動でマークされます(タップ不要)。
4. 勝利条件(初期は1ライン)に達すると自動でビンゴが申告され、あなたの順位が表示されます。
5. ホストが「ゲームを終了」すると順位が確定。上位(景品数まで)の当選者には当選コードが表示されるので、主催者に伝えて景品を受け取ります。

✨ 順位は「何球目でビンゴしたか」だけで決まるので、通信の速さや申告の早さは関係ありません。景品数を超える同着は公平に抽選されます。

🏠 オフラインで遊ぶ(会場向け・サーバー不要)

同じ会場で、ホストが番号を読み上げて手でマークする昔ながらの方式。ネット接続や Firebase は不要です。

🎪 ホスト QR表示・抽選・ビンゴ検証 🎫 プレイヤー カード受取・手動マーク

遊び方: ホストがゲーム作成 → 参加者がQRでカード受取 → ホストが番号を読み上げ → 参加者がタップでマーク → 1列そろったらビンゴ!カードのQRをホストに見せると、その場で検証できます。
